# Импорт подписки

Войдите в панель как администратор и откройте **Proxy subscription**. Вставьте публичную HTTPS-ссылку на подписку или её содержимое. Обычный текст и Base64 должны содержать по одному URI сервера на строку. Ограничение составляет 256 КиБ и 256 записей. Загрузчик принимает HTTPS на порту 443, проверяет TLS и разрешённые IP-адреса, перенаправления отклоняются.

- **VLESS**. TCP с TLS, UUID и явный порт. Поддерживаются имя TLS-сервера, отпечаток клиента, ALPN и `xtls-rprx-vision`.
- **Hysteria2 / hy2**. Один числовой порт, по умолчанию 443, учётные данные в URI, TLS SNI, ALPN и стандартные поля обфускации. Если провайдер прислал расширение `fm`, запись сохраняется с предупреждением о необходимости проверить эти параметры перед использованием.

При частичной ошибке сохраняются принятые записи, причины отклонения отображаются с номерами строк. Импорт с хотя бы одной принятой записью заменяет предыдущую подписку. При полном отказе сохраняется предыдущая подписка. Принятые строки показываются со статусом **Connectivity unchecked**. Проверка соединения с выбранным сервером и применение конфигурации относятся к следующим шагам.

URL загрузки используется только на время запроса. Принятые учётные данные сохраняются в файле `proxy-subscription.json` в закрытом каталоге состояния API с режимом `0600`. В браузер возвращаются только номера строк, протоколы и диагностические коды. Журнал API содержит счётчики и фиксированные коды ошибок.

Для проверки вставьте действительную подписку, затем отдельно отправьте строку с неподдерживаемым протоколом. Должна появиться ошибка конкретной строки. Перезагрузите страницу и убедитесь, что последний сохранённый отчёт снова доступен. Для проверки журнала смотрите записи `journalctl -u debian-router-api.service` с текстом `proxy subscription`.
