# WAN PPPoE

Панель PPPoE принимает логин и пароль провайдера для `enp1s0`. После временного применения она показывает состояние соединения: подключение, успешную сессию, ошибку аутентификации, отсутствие PPPoE-сервера или переподключение. Подтверждать настройки можно только после появления сессии. Если подтверждение не выполнено за 120 секунд, независимый таймер восстанавливает прежний профиль WAN.

Учётные данные хранятся только на устройстве в файле `/var/lib/debian-router-agent/pppoe-active/options` с правами `0600`. В ответах API и журнале проекта пароль отсутствует. Установщик добавляет пакет Debian `ppp` и службу `debian-router-pppoe.service`; без применённых настроек служба не запускает соединение.

На B5 проверены успешная PAP-сессия, ошибка входа, переподключение, отсутствие PPPoE-сервера и откат на изолированном виртуальном канале. Текущий физический WAN подключён к DHCP-роутеру, поэтому работу с реальным провайдером ещё нужно проверить при появлении такого подключения. Замена уже подтверждённой учётной записи PPPoE и переключение обратно на DHCP через UI пока не реализованы.
