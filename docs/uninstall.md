# Удаление приложения

Подключитесь через независимый канал управления или локальную консоль. Перед удалением переведите клиентов на другой маршрут, если они используют PPPoE, LAN DHCP/DNS или прокси этого роутера. Завершите восстановление резервной копии и подтвердите либо откатите незавершённые сетевые операции. Если правила маршрутизатора нужно снять, воспользуйтесь [процедурой отключения firewall](network-firewall.md), пока агент ещё установлен.

```sh
rm -f ./debian-router-install.sh && /usr/lib/apt/apt-helper download-file https://raw.githubusercontent.com/ASSever/debian-router-b5-2840/main/install.sh ./debian-router-install.sh
sudo sh ./debian-router-install.sh --uninstall
```

Команда останавливает службы приложения, снимает их с автозапуска и удаляет определения systemd и ссылки на активный выпуск. При запущенной службе PPPoE или LAN DHCP/DNS команда останавливается до удаления. После переноса этих функций остановите соответствующую службу и повторите команду.

Docker, Portainer, их контейнеры и тома остаются на устройстве. Конфигурация сети и файлы systemd, добавленные вручную как drop-in, сохраняются. Приложение также сохраняет SQLite, сертификаты, конфиги и файлы выпущенных версий для последующей установки. Обычная установка по [README](../README.md#запуск-на-чистом-debian) заново создаст службы и использует сохранённые данные.
