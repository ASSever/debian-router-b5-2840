# Смена подсети LAN и DHCP-пула

Подключите клиент к LAN-порту `enp2s0`. Для первого применения войдите в Web UI через существующий туннель управления. В **Network / LAN** задайте IPv4-адрес маршрутизатора с префиксом, начало и конец DHCP-пула. По умолчанию форма предлагает `192.168.10.1/24` и `192.168.10.100–192.168.10.200`. Пул должен лежать в той же подсети и исключать IP маршрутизатора, адрес сети и broadcast.

При конфликте с действующим IPv4-префиксом WAN или Wi‑Fi форма показывает интерфейсы и предлагает свободный вариант, если такой вариант найден. При отключённом WAN проверка использует доступные адреса и маршруты. Повторите проверку после подключения WAN.

До применения получите сертификат LAN через доверенный SSH-канал. Команда читает только публичный сертификат.

```sh
ssh user@ROUTER 'sudo systemd-run --pipe --quiet --collect -p DynamicUser=yes -p StateDirectory=debian-router-b5-2840 -p StateDirectoryMode=0700 /opt/debian-router-b5-2840/current/router-api lan-tls-certificate' > router-lan.crt
```

Доверьте этот сертификат клиенту управления, затем нажмите **Apply LAN temporarily**. Обновите DHCP-аренду на клиенте, чтобы получить новый IP, шлюз и DNS. Откройте [https://router.home.arpa:8443](https://router.home.arpa:8443/) через LAN, войдите и нажмите **Confirm LAN settings**. Если имя закешировано, обновите DNS-кэш клиента. Вход с текущего туннеля позволяет читать состояние и откатить изменения, а подтверждение принимает только HTTPS на новом LAN-адресе.

Если подтверждение не получено, таймер systemd возвращает прежний адрес, DHCP/DNS и правила доступа через пять минут. Кнопка **Restore previous LAN** запускает откат сразу. DHCP/DNS обслуживает отдельный dnsmasq. Таблица nftables `debian_router_lan` ограничивает LAN DNS и HTTPS. Маршрутизация клиентов в интернет и NAT добавляются на следующих этапах.

## DHCP-резервации

После подтверждения LAN добавьте запись в **DHCP reservations**, указав MAC клиента и доступный IPv4-адрес в этой подсети. У каждого MAC и IP может быть только одна запись. Для изменения используйте **Edit**, для удаления — **Delete**. Обновите аренду на клиенте, чтобы проверить выдачу. Перед переносом LAN в другую подсеть удалите несовместимые резервации и создайте их с новыми адресами после подтверждения LAN.
