# Обновление и откат версии

Скачайте свежую точку входа по первой команде из README. Перед обновлением сохраните [резервную копию](backup.md) и проверьте независимый доступ по SSH или через консоль. Для выбранного выпуска используйте его версию без начальной `v`.

```sh
sh ./debian-router-install.sh --check
sh ./debian-router-install.sh --fetch-version 0.1.0-step46-20261127-2326-r54
sudo sh ./debian-router-install.sh --install-version 0.1.0-step46-20261127-2326-r54
```

До переключения указателей установщик проверяет платформу и SHA-256 пакета и сверяет `VERSION` с запрошенной версией. После обновления проверьте `current/VERSION` и `agent-current/VERSION` в `/opt/debian-router-b5-2840`, вход в UI и доверенный HTTPS `/healthz`. Повторная установка той же версии сохраняет запущенный API, если его unit-файл уже соответствует установленному.

При обнаруженном отказе активации установщик возвращает указатели и затронутые unit-файлы. Перед перезапуском прежнего агента и API он сбрасывает счётчики стартов systemd, потому что их мог исчерпать кандидат. Неудачное обновление завершает команду с кодом 7 даже после успешного отката. Сообщение `Automatic rollback is incomplete` означает, что прежнюю службу запустить не удалось. Проверьте её состояние и журнал из консоли.

Откат версий проверен на r52 и r54 с общей схемой SQLite 2. Эта процедура возвращает версию программы и состояние служб при обнаруженном установщиком отказе. Восстановление данных из архива описано отдельно. Аварийное обесточивание и принудительное завершение установщика требуют отдельной процедуры восстановления.
