# Независимое восстановление Proxy

`debian-router-recovery.service` устанавливается выключенной. После включения она проверяет выбранного участника одной группы Proxy. Каждая проба запускает временный sing-box с одним сервером и выполняет HTTPS-запрос через него. Действующий sing-box и API для этих проб не требуются.

Две подряд неудачные пробы запускают проверку остальных участников в порядке группы. Служба переключает группу на первого участника, который вернул заданный HTTPS-код. Если запасные серверы недоступны, выбор сохраняется. Служба продолжает следить за выбранным после переключения сервером. Вернуть прежний выбор можно через обычное редактирование профиля.

Применение использует тот же механизм проверки конфигурации, смены поколения и отката, что и ручное изменение профиля. Если оператор изменил профиль в ходе проверки, результат относится к предыдущему поколению и не применяется. Перезапуск sing-box при переключении закрывает существующие прокси-соединения. Новые соединения используют выбранный резерв.

## Настройка

Создайте группу минимум из двух серверов в [профиле Proxy](proxy-routing.md). Укажите её в `/etc/debian-router-b5-2840/recovery.json`:

```json
{
  "group": "primary",
  "probe_url": "https://www.gstatic.com/generate_204",
  "expected_status": 204,
  "interval_seconds": 15
}
```

Проба требует доверенный сертификат и заданный код ответа без перенаправления. Поле `ca_file` указывает отдельный PEM-файл доверия для стенда. Интервал отсчитывается после завершения проверок. Журнал содержит имя группы, номера строк и итог проверки. Учетные данные серверов остаются в закрытом каталоге профиля.

```sh
sudo /opt/debian-router-b5-2840/current/router-recovery check-config
sudo systemctl enable --now debian-router-recovery.service
sudo journalctl -u debian-router-recovery.service -n 30
```

Перед ручной остановкой Proxy остановите и службу восстановления, если автоматический запуск Proxy на резерве следует приостановить.
