# Правила и группы Proxy

Войдите в панель, импортируйте подписку и откройте **Proxy rules and groups → Edit proxy profile**. Профиль действует на HTTP и SOCKS-подключения к `127.0.0.1:11080`. Для доменных правил передавайте прокси имя назначения, например через HTTP proxy или `socks5h`.

```json
{
  "default": "direct",
  "groups": [{ "name": "primary", "members": [1, 2], "selected": 2 }],
  "rules": [
    { "match": "exact", "domain": "skip.example.org", "target": "block" },
    { "match": "suffix", "domain": "example.org", "target": "group:primary" }
  ]
}
```

Подставьте номера принятых строк текущей подписки. Группа направляет трафик через `selected`, который должен входить в `members`. Правила проверяются от первого к последнему. `exact` совпадает с полным доменом, `suffix` совпадает с указанным доменом и его поддоменами. Допустимые назначения правил и `default` — `direct`, `block` и `group:имя`. Максимум 8 групп, 16 разных серверов и 32 правила.

При применении агент проверяет собранную конфигурацию, сохраняет её отдельным поколением и запускает sing-box. Успех означает готовность локального слушателя. Доступность участника группы проверяется отдельной кнопкой **Check server**. Если кандидат не запускается, агент возвращает предыдущий профиль и запускает sing-box с ним. Если восстановление прервётся, агент повторяет попытку при запуске. Профиль и содержащий секреты файл хранятся в закрытом каталоге состояния агента.

Для проверки маршрута подайте через прокси совпадающий и несовпадающий запросы и проверьте их на контролируемых получателях. Переключите участника между двумя такими получателями. При проверке отката сравните профиль и контрольный трафик до сбоя и после восстановления.
