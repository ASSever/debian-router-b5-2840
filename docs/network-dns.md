# DNS для LAN

После подтверждения профиля LAN откройте **LAN DNS**. Введите локальные записи по одной на строку, например `nas.home.arpa 192.168.10.20`. Поддерживаются записи A и AAAA. Для одного имени можно добавить несколько адресов. Для управления роутером используется встроенное имя `router.home.arpa`.

Задайте основной DNS-сервер и при необходимости резервный. Оба поля принимают IP. При пустых полях dnsmasq использует системные резолверы Debian. С заданным основным сервером dnsmasq сначала обращается к нему и переходит к резервному при повторе UDP-запроса, если основной молчит. Одиночный запрос без повтора в этом случае может истечь по тайм-ауту.

**Save DNS settings** применяет настройки к выделенной LAN-службе dnsmasq и правилам доступа. **Clear DNS cache** очищает кэш dnsmasq без перезапуска службы. Клиентские кэши управляются на клиентах.

Режим **Use router DNS only** блокирует пересылаемые через B5 DNS-запросы клиентов LAN на TCP и UDP 53. DHCP продолжает выдавать клиентам LAN-адрес B5 как DNS. Политика действует на маршрутизируемый трафик. DNS поверх HTTPS, TLS и прямые запросы между устройствами в одном сегменте относятся к другим механизмам фильтрации.
