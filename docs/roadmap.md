# План разработки

Каждая строка — отдельное изменение со своей проверкой. Рабочий код, тест и инструкция попадают в GitHub вместе. Каждый завершённый шаг выпускается новым versioned GitHub Release, устанавливается на B5 и проверяется там; результат фиксируется в локальном setup log. Фактические адреса, ключи, пароли и отчёты устройства хранятся локально. Состояние проверки на B5 записываем в журнал с датой, командой и результатом.

**Состояние на 20 ноября 2026 г.** На B5 установлены и проверены шаги 01–17. Восстановление после административного down/up подтверждено независимым systemd timer при закрытой SSH-сессии; физическая потеря carrier не тестировалась. [Релиз шага 16](https://github.com/ASSever/debian-router-b5-2840/releases/tag/v0.1.0-step16-20261120-1822-r9) установлен двумя командами из README; HTTPS health и API списка интерфейсов ответили успешно, UI и собранный JS мастера отдаются устройством. Чистая переустановка Debian с развёртыванием двумя командами пока не проводилась.

**Решение для будущей установки.** Начальная LAN-подсеть `192.168.10.0/24`, IP маршрутизатора `192.168.10.1`, DHCP-пул по умолчанию `192.168.10.100–192.168.10.200`. Это начальные значения настроек, а не постоянные значения в правилах firewall или шаблонах DNS. Страница Network/LAN должна позволять изменить адрес маршрутизатора, префикс и DHCP-пул. Перед сохранением проверять диапазон, пересечение с WAN и сетью управления. Перед применением показать новый адрес интерфейса, подготовить независимый откат и пересчитать связанные настройки DHCP, DNS и firewall. Действующую конфигурацию устройства изменим после появления и проверки этой функции.

**Начальное назначение портов B5-2840.** `enp1s0` — WAN, `enp2s0` — LAN. Пользователь подтвердил это назначение, и наличие линка на каждом интерфейсе проверено по очереди. Мастер должен хранить роли портов как изменяемую настройку и проверять их перед применением сети.
