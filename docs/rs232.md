# RS232

Утилита из пакета работает локально на B5. Для вывода списка устройств откройте SSH-сеанс и запустите:

```sh
cd /opt/debian-router-b5-2840/current
./router-rs232 list
```

Список сопоставляет узел Linux с путём контроллера в sysfs. Он включает зарегистрированные UART и адаптеры `ttyUSB*` и `ttyACM*`. Маркировку физического разъёма сопоставляют с устройством Linux по результату обмена. Для USB-адаптера проверьте, что на его выходе уровни RS232.

Подключите тестовое устройство или заглушку RS232 с петлёй TX–RX к свободному порту. Перед проверкой убедитесь, что порт свободен от `serial-getty` и других процессов. Для двух последовательных устройств используйте кабель с распайкой, соответствующей их разъёмам. Настройте тестовое устройство на ту же скорость, 8 бит данных, без чётности, один стоп-бит и без управления потоком.

```sh
sudo ./router-rs232 exchange -port /dev/ttyS0 -baud 9600 -timeout 2s \
  -send-hex 0052a5ff -expect-hex 0052a5ff
```

В примере тестовое устройство возвращает отправленные байты. Для ответа другим кадром укажите его в `-expect-hex`. Утилита очищает очереди порта перед отправкой и восстанавливает настройки терминала после проверки. Для успеха должны совпасть все ожидаемые байты. При тайм-ауте, несовпадении ответа или ошибке порта команда завершится с ненулевым кодом. Поддерживаются скорости 9600, 19200, 38400, 57600 и 115200. [Интерфейс termios](https://man7.org/linux/man-pages/man3/termios.3.html)
