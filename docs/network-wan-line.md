# Параметры линии DHCP WAN

Войдите в Web UI как администратор и откройте **DHCP WAN line settings**. Настройки действуют на WAN-порту `enp1s0` в режиме IPv4 DHCP.

| Поле | Значение |
| --- | --- |
| VLAN ID | От 1 до 4094. Пустое поле оставляет WAN без тега. |
| VLAN egress priority (PCP) | От 0 до 7. Применяется к исходящим кадрам с обычным приоритетом Linux 0 при включённом VLAN. |
| MTU | От 1280 до 1500, в пределах MTU исходного физического порта. Пустое поле использует исходный MTU. |
| MAC clone | Индивидуальный Ethernet MAC. Пустое поле использует исходный MAC. DHCP использует MAC в идентификаторе клиента при клонировании. |

Нажмите **Apply line settings temporarily**. При настроенном VLAN DHCP переключается на `router-wan-vlan`. Проверьте аренду, шлюз и WAN-соединение перед сохранением. При отсутствии подходящего DHCP-сервера подтверждение отклоняется. Независимый таймер возвращает предыдущий профиль через 120 секунд. Для немедленного отката нажмите **Restore line settings**.

Чтобы вернуться к обычному DHCP, очистите VLAN ID, MTU и MAC, примените и подтвердите настройки. Сделайте это перед переключением на Static IPv4 или PPPoE.
