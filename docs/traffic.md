# Счётчики трафика

Снимок доступен через `GET /api/network/traffic` с действующим сеансом администратора. Локальная команда на B5 возвращает те же данные в поле `traffic`.

```sh
sudo -g debian-router-agent /opt/debian-router-b5-2840/current/router-agent request traffic-status
```

- `interfaces` содержит накопительные `rx` и `tx` из сетевой статистики ядра для каждого интерфейса. Значения включают весь учтённый интерфейсом трафик. Один пакет может пройти через несколько интерфейсов. При пересоздании устройства счётчики начинаются заново. Поле `index` помогает обнаружить смену устройства.
- `clients` содержит `upload` и `download` по IPv4- и IPv6-адресам в действующих префиксах LAN, указанных в `lan_prefixes`. Учитываются IP-байты с заголовками и пакеты, видимые маршрутизатору. Трафик к роутеру и от него учитывается со стороны клиента. На входе измерение происходит до фильтрации и перенаправления, поэтому может включать пакеты, которые затем отбросит firewall. На выходе измерение происходит после трансляции адресов. Обмен напрямую между клиентами через коммутатор, ARP, IPv4 broadcast и IPv6 link-local не входят в учёт клиентов.
- IP-адрес определяет строку учёта. Несколько адресов одного устройства дают несколько строк, а смена владельца адреса может объединить трафик разных устройств. Каждый IP-стек и направление отслеживают до 512 адресов. Запись направления истекает через час без трафика. Для отсутствующего направления оставшейся строки возвращается ноль.
- `sampled_at` и `clients_since` указаны в UTC. Последнее поле отмечает создание текущих наборов. При перезапуске агента и изменении адресов или интерфейса LAN наборы создаются заново. Агент сверяет адреса примерно каждые пять секунд и при запросе снимка. Пустой список при пустом `lan_prefixes` означает, что адрес для учёта на LAN ещё не назначен. Ошибка получения снимка возвращает HTTP 503.

Снимок читается двумя запросами к ядру, поэтому приросты по интерфейсу и клиенту могут различаться по времени, уровню учёта и составу трафика. Хранение истории и графики запланированы для шага 38.
