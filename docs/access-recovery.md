# Локальное восстановление доступа

На локальной консоли B5 войдите в Debian под пользователем с правом `sudo`. Выполните команду в интерактивном терминале:

```sh
sudo systemd-run --pipe --quiet --collect -p DynamicUser=yes -p StateDirectory=debian-router-b5-2840 -p StateDirectoryMode=0700 /opt/debian-router-b5-2840/current/router-api admin-reset
```

Команда покажет временный пароль один раз. Сброс сразу отзывает все ранее выданные веб-сеансы и заменяет прежний пароль. Команда использует тот же каталог состояния, что и API. Перезапуск службы не требуется.

Откройте веб-интерфейс по HTTPS с доверенным сертификатом, как описано в [README](../README.md#веб-интерфейс). Войдите с временным паролем и задайте новый пароль длиной от 12 до 1024 байт. При смене пароля временный сеанс завершается. Войдите ещё раз с новым паролем и откройте панель администратора.
